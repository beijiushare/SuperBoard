# SuperBoard 手动测试清单

> 测试方式：用户手动测试，助手一次只给一项。每项包含操作步骤、预期结果、需要提供的反馈。
> 用户反馈后再进入下一项。

## 反馈格式

失败时请尽量提供：

- 当前 URL（含 `?board=`、`?scope=`、`?tree=` 参数）
- 浏览器和系统版本
- 操作步骤（越具体越好）
- 截图：完整页面 + 出问题的局部放大图
- 控制台报错：DevTools → Console，截图或复制文字
- 网络报错：DevTools → Network 中失败的请求（尤其 `/__canvases`、`/__folders`）
- 涉及保存/导出时：保存后的 `.canvas` 文件或导出的 SVG/PNG/HTML 文件
- 预期结果 vs 实际结果

涉及拖动、缩放、框选等动态问题，能录屏最好；不方便就描述鼠标起点、终点和屏幕缩放比例。
