# 本次交付与实测清单

## 一、本次交付范围

本次交付集中在 Markdown 渲染/编辑、选择与箭头交互、视口控件、主题系统，以及编辑器大文件拆分。

### 1. Markdown 展示态

- 展示态从 `react-markdown` 切换为 Vditor 静态渲染：`Vditor.md2html` + `Vditor.mathRender`。
- 公式与 IR 编辑态共用同一套 AsciiMath MathJax。
- 带 `<iframe>` 的内容自动回退到 `MarkdownView`，避免安全清洗行为差异。
- 静态预览支持代码高亮：
  - Purple 使用 `github`
  - Orange / Mint 使用 `atom-one-dark`
- 块级公式在当前宽度内水平居中。
- Markdown 内容内边距调整为 `18px 20px`，行内编辑同步。
- 修复编辑态 Vditor 默认灰色 panel 背景，行内编辑透明白底，专注编辑透出弹窗底色。

### 2. Markdown 编辑态

- 行内编辑保留块自身旋转，不再自动转正整个画布。
- 专注编辑弹窗使用 Vditor IR。
- `Ctrl/Cmd + Enter` 提交并退出编辑。
- 进入编辑时不再出现错误视口导致的残影。
- 退出编辑时点击事件继续透传，可一次完成“退出 + 选中/取消选中”。
- 编辑态不显示缩放/旋转手柄，只保留编辑边框。

### 3. Markdown 主题

- 三种主题：Purple、Orange Heart、Mint。
- 主色：
  - Purple `#8064a9`
  - Orange `#ef7060`
  - Mint `#4eb289`
- 字体：PingFang 优先，其次 Windows 常见字体。
- 主题写入：
  - 节点：`x-superboard.markdownTheme`
  - 白板默认：`x-superboard.markdownDefaultTheme`
- 新建 Markdown 块继承白板默认主题。
- 展示态、行内编辑、专注编辑共用同一主题 class。
- 补全了各主题的标题、链接、引用、表格、代码块、行内代码和部分间距细节。
- 致谢中补充：
  - https://github.com/hliu202/typora-purple-theme （使用 `purple.css`）
  - https://gitee.com/golikang/typora-theme-orange-heart
  - https://github.com/Y1chenYao/typora-mint-theme

### 4. 选择、工具栏、箭头

- 选择框几何集中到 `selectionChrome.ts`。
- 角的方形手柄、旋转手柄、边命中区、光标统一。
- 手柄命中区大于视觉区域。
- 极小选择框减少角手柄，过小时隐藏旋转手柄。
- 浮动工具栏：
  - 拖动/缩放/旋转时隐藏
  - 按实际尺寸和旋转角 clamp 在可视区域内
  - 顺序：锁定比例、编辑、专注编辑、设置颜色、删除
- 箭头：
  - 拖拽时高亮目标块
  - 显示四个侧边吸附点
  - 当前吸附侧按指针位置高亮
  - 松手按指针靠近的侧边连接

### 5. 视口控件

- 小地图、缩放悬浮条整体缩小到 0.7 倍。
- 小地图默认折叠。
- 缩放悬浮条默认折叠。
- 折叠按钮保留，展开后保持 0.7 倍。
- 对齐线透明度降低到 0.32，只在块实际移动超过 3px 后显示。

### 6. 清理

- 删除根目录 `canvas-editor.html`。
- 删除根目录 `canvas-preview.html`。

  - 统一 Vditor CDN 路径，适配 `BASE_URL`。
- 新增 `patches/vditor+4.0.1.patch`：
  - 将 Vditor MathJax 管线从 TeX 改为 AsciiMath。
  - 锁定 `vditor@4.0.1`。
  - `postinstall` 自动应用补丁并清理 Vite 缓存。

## 二、验证命令

```bash
npm install
npm run clear:vite
npm run dev
```

另开终端：

```bash
npm run typecheck
npm run build:site
```

说明：

- `npm install` 会执行 `patch-package`。
- 如果之前启动过 dev server，更新 Vditor 补丁后必须重启 dev server。
- `npm run clear:vite` 用于清除 Vite 依赖预构建缓存。

## 四、已知限制

- 主题是参考 Typora 主题的简化移植，不是原 CSS 的完整逐行复刻；标题装饰、Callout、任务列表、脚注、TOC、图片说明等仍有差异。
- Vditor 静态预览目前只对代码块做 highlight，不渲染 Mermaid 等重型扩展；原有 Markdown 使用代码块展示 Mermaid 的方案保持不变。
- 带 iframe 的 Markdown 块使用旧 `MarkdownView`，主题 wrapper 已保留，但展示引擎与普通块不同。
- Vditor 补丁依赖 `4.0.1`；升级 Vditor 时需要重新生成/校验补丁。
- 如果更新补丁后开发服务器没有重启，Vite 可能仍使用旧的 Vditor 预构建缓存；使用 `npm run clear:vite` 后重启。
- `whiteboards/public/asddd.canvas` 是本地测试数据，当前未提交；`.canvas.*.tmp` 是保存过程临时文件。
