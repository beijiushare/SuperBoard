# 样式面板重构设计

## 目标

统一白板编辑器样式面板的字段结构，消除块与形状面板的重复逻辑，并修复长标签换行、画布背景透明度缺失、圆角不可连续调节等问题。

本轮同时调整两处交互：

- 自由绘图完成一笔后不自动选中该笔。
- 箭头颜色字段标签改为「颜色」。

## 非目标

- 本轮不重做文本编辑体验。
- 本轮不实现空白处双击快速菜单。
- 拖拽被浏览器原生行为截获的问题暂不修改，待复现后单独处理。

## 面板结构

### 未选中

「画布」分组包含：

- 背景颜色
- 背景透明度
- 网格：无 / 点 / 线
- 对齐提示开关

「缩放」「新增元素」继续保留为独立分组。

### 选中普通块或形状

公共分组：

- **变换**：角度、宽度、高度
- **背景**：颜色、透明度
- **边框**：颜色、透明度、粗细、线型

条件分组：

- **文本**：仅文本块显示，保留字体、字号、颜色、加粗/斜体/下划线、对齐
- **圆角**：仅圆角矩形显示，普通矩形不显示
- **媒体裁剪**：仅媒体块显示，保留现有矩形/圆角/圆形裁剪能力
- **箭头**：选中箭头时显示，颜色标签使用「颜色」
- **排列**：多选时显示

自由绘图不显示背景和线型；线条形状不显示背景。

## 复用结构

在 `CanvasStylePanel` 内抽取以下字段组：

- `TransformFields`
- `BackgroundFields`
- `BorderFields`
- `TextFields`
- `CanvasFields`
- `MediaCropFields`

字段组只负责渲染和回调，不直接修改文档。面板继续使用现有的 `onBeforeChange` / `onApply` 流程。

删除现有重复的「形状」填充/描边区，形状统一使用公共背景与边框字段。

## 数据与行为

### 画布背景透明度

在 `SuperBoardCanvasSettings` 增加可选字段：

```ts
backgroundOpacity?: number
```

默认值为 `1`。渲染画布背景时，将背景颜色与透明度合成为半透明颜色；透明度为 `100%` 时保持现有显示。

### 圆角

在节点扩展中增加可选字段：

```ts
roundedRect?: boolean
```

创建圆角矩形时写入 `roundedRect: true`。样式面板显示圆角字段的条件：

- `roundedRect === true`，或
- 兼容旧数据：`shape === 'rect'` 且 `cornerRadius > 0`

因此把圆角调到 `0` 后字段仍然保留，普通矩形不会出现圆角字段。

圆角使用 `StyleNumberControl`，同时提供滑杆和数值输入：

- 最小值 `0`
- 最大值 `Math.min(width, height) / 2`
- 步长 `1px`

拖动滑杆和输入数值都会走现有历史合并与保存流程。

### 自由绘图

`commitStroke` 创建新绘图节点后，不再把新节点设为选中项，保持当前绘图工具，允许连续绘制下一笔。

### 排列

排列按钮固定为三行：

1. 左对齐、右对齐、顶部对齐、底部对齐
2. 垂直居中、水平居中
3. 横向分布、纵向分布

每一行使用独立 flex 行，不换行。

## 样式

- 统一字段标签宽度，并设置 `white-space: nowrap`。
- 覆盖 `.sb-style-row > span`、`.sb-style-number-label`、`.sb-color-control-label`，避免「背景颜色」「背景透明度」等标签换行。
- 排列区新增行容器样式，每行四列或两列，按钮保持现有视觉规范。

## 验证

自动检查：

- `npm run typecheck`
- `npm run test:model`
- `npm run test:editor`
- `npm run build:site`

手动检查：

- 长标签不换行，面板不横向溢出。
- 普通块、形状、文本块、媒体块分别显示正确分组。
- 画布背景透明度生效。
- 圆角滑杆与数值输入同步。
- 自由绘图连续画多笔，不会选中上一笔。
- 排列按钮按三行显示。
- 箭头颜色标签显示为「颜色」。
- 媒体裁剪的矩形、圆角、圆形模式仍可使用。
