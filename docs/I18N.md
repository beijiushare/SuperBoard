# 界面语言（i18n）

## 目录

```
web/src/i18n/
  index.ts                  # i18next 初始化、语言检测、切换
  errors.ts                 # 后端错误码 -> 文案
  locales/
    zh-CN/                  # 简体中文
    zh-TW/                  # 繁體中文（台灣用語）
    en-US/                  # English
      common.json
      start.json
      settings.json
      editor.json
      viewer.json
      errors.json
```

一个语言有 6 个命名空间文件；2 种语言 = 12 个文件，3 种 = 18 个。所有 JSON 静态 import 进 bundle，没有运行时按需加载。

## 键与命名空间

JSON 里是扁平的点号键，不是嵌套对象：

```json
{ "workspace.autoOpen.title": "自动进入最近工作区" }
```

组件里按 `命名空间:键` 使用：

```ts
t('settings:workspace.autoOpen.title')
```

## 语言来源与持久化

启动时按以下顺序决定：

1. 桌面端 `config.json` 的 `language`
2. `localStorage['superboard.language']`
3. 浏览器 `navigator.language`

只识别 `zh-CN`、`zh-TW`、`en-US`：

- `en*` → `en-US`
- `zh-TW` / `zh-HK` / `zh-MO` / `zh-Hant*` → `zh-TW`
- 其余 → `zh-CN`

默认与兜底语言是 `zh-CN`。

切换语言时 `setAppLanguage()` 会更新 i18next、localStorage、`<html lang>`，桌面端还会调用 Go 的 `SetLanguage` 写入 `config.json`。

## 校验

```bash
npm run check:i18n
```

比较每个非基准语言与 `zh-CN` 的 key 集合，缺 key 或多 key 都会失败。当前输出：`3 locales, 6 namespaces OK`。

## AI 回答语言

知识树的提示词在 `web/src/canvas/tree/treePrompt.ts`，按 `AppLanguage` 提供三套：

- 系统提示（结构、表格边界、标题规则）
- 压缩 / 增量压缩提示
- 引用格式、摘要前缀、压缩任务句

调用方通过 `getAppLanguage()` 传入，所以界面是繁体或英文时，回答、摘要、引用都会使用对应语言。新增语言必须同时补这套提示，否则会出现“界面是 A 语言、回答是中文”的割裂。

## 原生对话框

Go 侧不读前端 JSON。`desktop/services/config.go` 的 `nativeTexts` 按 key + 语言存标题：

```go
nativeTexts["workspace.select"]["zh-TW"] // 選擇 SuperBoard 工作區
```

调用处只传 key：`uiText("workspace.select")`。未知语言先回退到同语系（`zh-*` → `zh-CN`，`en-*` → `en-US`），再回退 `zh-CN`。

新增语言时需要同步：

1. `locales/<lang>/` 下 6 个 JSON；
2. `index.ts` 的 import、`resources`、`SUPPORTED_LANGUAGES`、`detectLanguage()`；
3. `treePrompt.ts` 的 `PromptSet`；
4. `config.go` 的 `nativeTexts` 与 `SetLanguage` 白名单；
5. 语言下拉的显示名（`common:language.<lang>`）。
